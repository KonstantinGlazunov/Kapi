# Kapi — учимся считать с Капи

Kapi — адаптивная браузерная игра для тренировки счёта. Ребёнок решает короткие серии примеров, а Капи отвечает на результат цельной анимационной сценой: поддерживает после ошибки, отмечает исправление, празднует серии правильных ответов и завершение тренировки.

Приложение работает как статический PWA без серверной части и сборки. Интерфейс доступен на русском и немецком языках, данные хранятся только в браузере пользователя.

## Запуск

Для локального запуска нужен любой статический HTTP-сервер:

```bash
cd dist
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

Режим проверки всех реакций Капи доступен по адресу:

```text
http://localhost:8080/?kapiTest=1
```

Он не изменяет учебный прогресс и историю тренировок.

## Возможности

- тренировки на 10, 20 или 30 примеров;
- 41 этап программы: от количества предметов до степеней и корней;
- автоматический адаптивный режим и ручной выбор операций;
- очередь ошибок с повторением до двух правильных решений подряд;
- персональный темп и система XP;
- реакции на ответ, серии, переход уровня и итог тренировки;
- плавная покадровая анимация составного персонажа на Canvas;
- готовые CC0-звуки с генеративным резервным сигналом;
- офлайн-работа после первого открытия;
- поддержка `prefers-reduced-motion`.

## Структура проекта

```text
dist/
  index.html              интерфейс приложения
  app.js                  игровая логика, программа и хранение данных
  kapi-motivation.js      выбор мотивационной реакции
  kapi.js                 машина состояний и Canvas-аниматор
  kapi-sound.js           звуковой менеджер
  styles.css              оформление и CSS-движение оболочки Canvas
  sw.js                   офлайн-кэш PWA
  assets/                 изображения, части рига и звуки
rive/                     экспериментальная Rive-разметка персонажа
tests/                    интеграционные проверки ключевой логики
docs/                     продуктовая и техническая документация
```

`dist/` — одновременно исходный код и публикуемый каталог. Отдельного шага сборки нет.

## Проверка

```bash
node --test tests/motivation.test.cjs
```

Тесты проверяют приоритет реакций, разные финалы для 10/20/30 примеров, очередь ошибок, непрерывность головы внутри сцены, движение прыжка, звуковые приоритеты, изоляцию тестового режима и наличие офлайн-ассетов.

## Развёртывание

Для публикации достаточно отдать содержимое `dist/` статическому хостингу по HTTPS. Service Worker регистрируется из корня приложения, поэтому сайт рекомендуется размещать в корне домена или сохранить ожидаемую структуру путей.

Текущая размещённая версия: [schitaem-s-kapi.lsdglider.chatgpt.site](https://schitaem-s-kapi.lsdglider.chatgpt.site/).
