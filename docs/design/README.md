# Kapi Design References

These images are approved visual references for the Kapi project.

They are used as the source of truth for UI/UX tasks.

When implementing screens, Codex must:
- compare against the corresponding reference;
- preserve the composition;
- preserve the visual hierarchy;
- preserve the atmosphere;
- avoid replacing the scene with a simplified interpretation unless necessary.
