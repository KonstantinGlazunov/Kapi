# Parent skill report

The report is local to this installation and does not affect training adaptation or rewards. Each completed exercise contributes one deduplicated observation. Invalid or incomplete input is not an arithmetic attempt; leaving an exercise does not create a result. Legacy history remains available but is not converted into inferred attempts.

Product thresholds live in `dist/kapi-parent-report.js`: fewer than five observations means getting acquainted; otherwise the last 20 are considered. Ten observations and at least 70% correct first attempts without assistance give growing confidence. Independent mastery requires at least 85%, an independently correct typed answer, and independent successes in different sessions on different calendar days. Choice-only evidence is identified and cannot produce the highest status. Speed never changes status. One difficulty cannot lower a confirmed status: three difficulties among the last five observations after confirmation are required before a lower candidate status is accepted. Persistent difficulty is described gently. Both skills and available subskills are assessed.

Observation details retain the latest 60 per skill/subskill bucket. Compact cumulative totals remain for each skill and subskill; the last 10,000 execution IDs prevent duplicates. Data is saved in a transactional IndexedDB scoped to the application path. A failed write leaves the observation pending in memory and displays a warning; partial backups are identified. Multiple tabs synchronize through notifications. Backup version 2 validates and includes report data; version 1 is supported without inventing missing observations. Restore checks for concurrent changes and rolls back local settings on failure.

Active independent time pauses while settings are open, the window is unfocused or the tab is hidden, and stops at the first valid attempt. It is descriptive data only. Weekly improvement requires at least five comparable observations in each week, same skill, subskill, stage, operation, task type and answer format, and a difference of at least 20 percentage points. Report wording is generated locally from recorded evidence.
